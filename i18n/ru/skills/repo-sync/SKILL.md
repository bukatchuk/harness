Синхронизируй репозитории. Аргументы: $ARGUMENTS

1. Запусти `bin/harness sync` (или `bin/harness sync <имя>` для одного проекта).
2. Скрипт безопасен для локальной работы: недостающее клонирует, существующее обновляет только при чистом дереве и только fast-forward. Остальное он помечает «только fetch» и не трогает.
3. Для репозиториев с пометкой «только fetch» или «ОШИБКА» покажи подробности: `bin/harness status`. Сам не делай `stash`, `reset`, `rebase` — предложи владельцу варианты.
4. Сообщи кратко: сколько клонировано, сколько обновлено, что требует внимания.
