Проверь окружение.

1. Запусти `bin/harness doctor --deep`. Скрипт проверяет только наличие токенов и коды ответов; значения токенов он не выводит — и ты не выводи.
2. Сгруппируй результат для владельца: что работает (одной строкой), что требует действия.
3. По каждому `FAIL` и `warn` дай конкретный следующий шаг:
   - утилита не установлена — команда установки для этой ОС (на macOS — `brew install …`, для `ggshield` — `pipx install ggshield`);
   - владелец не задан или правила не развёрнуты — `bin/harness init`;
   - токен не задан — в какую переменную его положить и где он выпускается (см. `.claude/integrations/<сервис>.md`);
   - HTTP 401/403 — токен просрочен или не хватает прав;
   - нет профиля `yc` или запрос к Yandex Cloud не прошёл — владельцу выполнить `yc init` (вход интерактивный, см. `.claude/integrations/yandex-cloud.md`);
   - нет соединения — проверить сеть или VPN и доступность сервиса.
4. Устанавливать утилиты и менять конфигурацию окружения — только с согласия владельца.
